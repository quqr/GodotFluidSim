# LiquidSim 流体模拟使用说明

基于 Godot 4 C# Compute Shader 的实时 2D 流体模拟插件。

本插件包含三个核心节点：**FluidSimulation2D**（模拟主节点）、**FluidEmitter**（流体发射器）、**FluidForceEmitter**（力发射器）。本文档详解每个参数的作用、默认值与调参建议。

## 一、快速上手

最小可运行场景只需三步：

1. 在场景中添加 `FluidSimulation2D` 节点，配置 `FluidWorldSize` 与显示纹理 `OutputTexture`。
2. 添加 `FluidEmitter` 节点作为子节点或场景中的任意节点，它会自动查找 `fluid_sim_nodes` 组中的 `FluidSimulation2D`。
3. 运行场景，发射器会按 `EmitInterval` 持续向流体中注入颜色和速度。

参考实现见 `Scenes/world_fluid_test.tscn`。

## 二、FluidSimulation2D 模拟主节点

`FluidSimulation2D` 是流体模拟的核心，负责管理 GPU 资源、调度渲染管线、维护模拟状态。所有发射器与障碍物都通过它驱动。

### 2.1 分辨率与域

| 参数                     | 类型         | 默认值            | 说明                                                                         |
| ---------------------- | ---------- | -------------- | -------------------------------------------------------------------------- |
| `SimulationResolution` | `Vector2`  | `(228, 128)`   | 模拟网格分辨率（宽×高）。速度/压力/散度/涡度场均在此分辨率计算，直接决定物理精度与性能开销。值越大流体细节越丰富，但 GPU 计算量按面积增长。 |
| `DyeResolution`        | `Vector2`  | `(1820, 1024)` | 染料/颜色场分辨率。通常远高于 `SimulationResolution` 以保证视觉清晰度，仅影响颜色纹理精度，对物理模拟无影响。        |
| `FluidWorldSize`       | `Vector2`  | `(1920, 1080)` | 流体域在世界空间中的实际尺寸（宽×高，单位：像素）。用于世界坐标 ↔ UV 坐标的转换，应与显示目标尺寸匹配。                    |
| `FollowNodePath`       | `NodePath` | `null`         | 跟随节点路径。若设置，流体域中心会跟随该节点移动，并产生帧间域偏移（Shift Texture），实现"无限流体"效果。               |

**调参建议**：

- 移动端或低端设备：`SimulationResolution` 降至 `(128, 72)`，`DyeResolution` 降至 `(910, 512)`。
- 高端桌面：`SimulationResolution` 可提升至 `(456, 256)`，`DyeResolution` 提升至 `(2560, 1440)`。
- `SimulationResolution` 与 `DyeResolution` 的宽高比应尽量保持一致，避免流体拉伸变形。

### 2.2 物理参数

| 参数                    | 类型      | 默认值    | 说明                                                                                                         |
| --------------------- | ------- | ------ | ---------------------------------------------------------------------------------------------------------- |
| `PressureIterations`  | `int`   | `20`   | Jacobi 迭代求解压力场的次数（WFS `PRESSURE_ITERATIONS`）。次数越多流体的不可压缩性约束越好，涡旋更稳定，但开销线性增长。建议 15\~40。                     |
| `VelocityDissipation` | `float` | `0.2`  | 速度场衰减系数（WFS `VELOCITY_DISSIPATION`）。每帧速度场乘以 `1 - dissipation × dt`（近似），正值使速度逐渐减小。0 = 无衰减，流体永动；1 = 快速静止。    |
| `DensityDissipation`  | `float` | `1.0`  | 颜色/密度场衰减系数（WFS `DENSITY_DISSIPATION`）。每帧颜色场乘以衰减因子，正值使颜色逐渐淡出。0 = 颜色永不消散；值越大颜色消散越快。                          |
| `Curl`                | `float` | `30.0` | 涡度增强强度（WFS `CURL`）。值越大流体旋转细节越明显，能恢复被离散化抹平的小尺度涡旋。0 = 关闭涡度增强；过大可能出现噪声状伪影。                                    |
| `Pressure`            | `float` | `0.8`  | 压力残留系数（WFS `PRESSURE`）。每帧压力场先乘以此值再进入 Jacobi 迭代，实现压力的"惯性残留"。1.0 = 完全保留上帧压力（更稳定但扩散慢）；0 = 每帧从零开始求解（更锐利但可能震荡）。 |
| `EnableVorticity`     | `bool`  | `true` | 是否启用涡度增强（Vorticity Confinement）。关闭后即使 `Curl > 0` 也不执行涡度计算，可省一点 GPU 开销。                                     |

**调参建议**：

- 想要"烟雾/墨水"般的长拖尾：降低 `VelocityDissipation` 到 `0.05~0.1`，`DensityDissipation` 降到 `0.3~0.5`。
- 想要"水花四溅"的明快反应：`VelocityDissipation` 提到 `0.5`，`Curl` 提到 `40~50`。
- 想要稳定的层流：`PressureIterations` 提到 `30+`，`Curl` 降到 `10~20`。

### 2.3 输入与交互

| 参数                      | 类型      | 默认值            | 说明                                                                                                              |
| ----------------------- | ------- | -------------- | --------------------------------------------------------------------------------------------------------------- |
| `SplatRadius`           | `float` | `0.25`         | Splat 基础半径（UV 空间，WFS `SPLAT_RADIUS`）。实际传入 shader 时除以 100，因此默认值为 `0.0025`。控制鼠标拖动/发射器注入时单点高斯分布的扩散范围。值越大单次注入的扩散越广。 |
| `SplatForce`            | `float` | `6000`         | Splat 力度系数（WFS `SPLAT_FORCE`）。控制鼠标拖动或外部输入产生的速度强度。`WorldFluidTest.cs` 中鼠标速度 = `deltaUV × SplatForce`。            |
| `ClearColor`            | `Color` | `(0, 0, 0, 0)` | 流体颜色纹理的清除色，也是流体的初始背景色。通常保持透明黑 `(0,0,0,0)`；若需要固定底色可改为不透明色。                                                       |
| `ObstacleForceStrength` | `float` | `5.0`          | 障碍物对流体施加的排斥力强度。值越大障碍物边缘的"推开"效果越明显。0 = 障碍物仅阻挡流体不额外施力。                                                            |

### 2.4 显示与开关

| 参数              | 类型     | 默认值    | 说明                                                                     |
| --------------- | ------ | ------ | ---------------------------------------------------------------------- |
| `Enabled`       | `bool` | `true` | 是否启用流体模拟。设为 `false` 时停止渲染并清空流体状态，输出纹理会被置空以释放 GPU 资源。切换为 `true` 时自动恢复。  |
| `EnableShading` | `bool` | `true` | 是否启用 Display 着色效果（WFS shading）。开启后流体表面会根据速度场法线计算光照，产生立体感。关闭则直接输出原始颜色场。 |

### 2.5 公共 API（代码调用）

| 方法                                                            | 说明                                                       |
| ------------------------------------------------------------- | -------------------------------------------------------- |
| `WorldToFluidUV(worldPos)`                                    | 世界坐标 → 流体 UV 坐标 `[0,1]`。用于 Splat 操作定位注入点。                |
| `WorldToFluidPos(worldPos)`                                   | 世界坐标 → 流体像素坐标 `[0, SimulationResolution]`。用于力发射器 GPU 参数。 |
| `WorldToDyePos(worldPos)`                                     | 世界坐标 → 染料像素坐标 `[0, DyeResolution]`。                      |
| `QueueDraw(uv, color, velocity, colorRadius, velocityRadius)` | 将一次绘制请求入队，下帧渲染时统一执行 Splat。`uv` 为 `[0,1]` 坐标。             |
| `QueueDrawBatch(points[], colors[], velocities[], radii[])`   | 批量入队，性能优于循环调用 `QueueDraw`。发射器内部使用此方法。                    |
| `ClearFluid()`                                                | 清空所有流体状态（速度、压力、颜色），异步在渲染线程执行。                            |
| `MarkInputForcesDirty()`                                      | 标记 `InputForcesImg` 已修改，下帧上传到 GPU。                       |
| `MarkInputColorsDirty()`                                      | 标记 `InputColorsImg` 已修改，下帧上传到 GPU。                       |
| `SetObstacleRawData(byte[])`                                  | 设置障碍物原始数据（Rgba32f 格式，每像素 16 字节）。                         |

## 三、FluidEmitter 流体发射器

`FluidEmitter` 是向流体注入**颜色和速度**的节点。它支持三种发射模式、五种发射形状、三种速度模式。发射器会自动查找场景中的 `FluidSimulation2D`（通过 `fluid_sim_nodes` 组）。

### 3.1 发射模式

| 参数                 | 类型             | 默认值          | 说明                                                                   |
| ------------------ | -------------- | ------------ | -------------------------------------------------------------------- |
| `EmissionModeType` | `EmissionMode` | `Continuous` | 发射模式枚举。详见 [5.2 EmissionMode](#52-emissionmode)。                      |
| `EmitInterval`     | `float`        | `0.05`       | `Continuous` 模式下的发射间隔（秒）。值越小发射越频繁，`0.02` ≈ 每帧发射一次（60fps）。            |
| `BurstCount`       | `int`          | `10`         | `SingleBurst` / `PeriodicBurst` 模式下每次爆发的粒子数量。                        |
| `BurstInterval`    | `float`        | `1.0`        | `PeriodicBurst` 模式下的爆发间隔（秒）。                                         |
| `MaxBurstCount`    | `int`          | `512`        | 单次爆发的粒子上限，防止 `BurstCount` 过大导致性能问题。同时作为颜色/半径缓存数组大小。                  |
| `Lifetime`         | `float`        | `0`          | 发射器生命周期（秒）。`0` = 永不过期。到期后根据 `AutoDestroy` 决定行为。                      |
| `AutoDestroy`      | `bool`         | `false`      | 生命周期到期后是否自动 `QueueFree()` 销毁节点。`false` 时仅将 `Active` 置为 `false` 停止发射。 |
| `Active`           | `bool`         | `true`       | 是否激活发射器。`false` 时停止所有发射逻辑。                                           |

### 3.2 发射形状

| 参数                  | 类型                | 默认值        | 说明                                                                                                                                                      |
| ------------------- | ----------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `EmissionShapeType` | `EmissionShape`   | `Point`    | 发射形状枚举。详见 [5.1 EmissionShape](#51-emissionshape)。                                                                                                       |
| `ShapeSize`         | `Vector2`         | `(1, 1)`   | 发射形状尺寸，**单位为世界坐标**。不同形状的语义：• `Point`：忽略• `Circle`：`X` 为半径• `Rect`：`X/Y` 为半宽/半高• `Line`：`X` 为半长，`Y` 忽略（垂直方向有 ±0.1 随机偏移）• `TextureMask`：`X/Y` 为遮罩纹理缩放的半尺寸 |
| `MaskTexture`       | `Texture2D`       | `null`     | 纹理遮罩。仅 `EmissionShapeType = TextureMask` 时生效。根据纹理 Alpha 通道决定粒子分布位置（拒绝采样法）。                                                                              |
| `UseTextureColor`   | `bool`            | `false`    | 是否使用遮罩纹理的颜色作为发射颜色，替代 `EmitColor`。仅 `TextureMask` 模式有意义。                                                                                                 |
| `SampleMode`        | `RangeSampleMode` | `Interior` | 范围采样模式。仅当发射器有 `CollisionShape2D` 子节点时生效。详见 [5.5 RangeSampleMode](#55-rangesamplemode)。                                                                  |

> **优先级说明**：若发射器有 `CollisionShape2D` 子节点（`RectangleShape2D`/`CircleShape2D`/`CapsuleShape2D`/`ConcavePolygonShape2D`），则优先使用碰撞形状采样，忽略 `EmissionShapeType`。无碰撞形状或形状不支持时回退到 `EmissionShapeType`。

### 3.3 速度配置

| 参数                    | 类型                | 默认值           | 说明                                                                                                   |
| --------------------- | ----------------- | ------------- | ---------------------------------------------------------------------------------------------------- |
| `VelocityPatternType` | `VelocityPattern` | `Directional` | 速度方向模式枚举。详见 [5.3 VelocityPattern](#53-velocitypattern)。                                              |
| `EmitVelocity`        | `Vector2`         | `(0, -1)`     | 速度方向和基础大小。• `Directional`：所有粒子沿此固定方向发射• `Radial`：仅使用长度作为速度大小• `Random`：仅使用长度作为速度大小                   |
| `VelocityFalloff`     | `float`           | `0`           | 径向模式下的速度衰减指数。`0` = 无衰减（边缘速度与中心一致）；值越大边缘速度越慢。计算公式：`falloff = 1 - (dist / maxDist) ^ VelocityFalloff`。 |
| `SwirlStrength`       | `float`           | `0`           | 旋转扰动强度。为每个粒子叠加切向速度分量 `tangent × SwirlStrength`，产生旋涡效果。`0` = 无旋转。正值逆时针，负值顺时针。                         |

### 3.4 颜色与半径

| 参数               | 类型      | 默认值                    | 说明                                                                                        |
| ---------------- | ------- | ---------------------- | ----------------------------------------------------------------------------------------- |
| `EmitColor`      | `Color` | `(0.5, 0.5, 0.5, 0.5)` | 发射颜色，RGBA 格式。`Alpha` 通道控制注入强度（0\~1）。最终颜色会乘以此值后写入颜色场。                                      |
| `ColorRadius`    | `float` | `0.5`                  | 颜色注入半径倍率。最终半径 = `SplatRadius / 100 × ColorRadius`。值越大单点颜色扩散越广。                            |
| `VelocityRadius` | `float` | `0.8`                  | 速度注入半径倍率。最终半径 = `SplatRadius / 100 × VelocityRadius`。通常略大于 `ColorRadius` 以保证速度影响范围覆盖颜色范围。 |

## 四、FluidForceEmitter 力发射器

`FluidForceEmitter` 是向流体施加**方向性外力**的节点，不注入颜色。支持五种力模式、五种作用形状。非 `TextureMask` 形状使用 GPU 并行计算力场；`TextureMask` 或 `CollisionShape2D` 形状回退到 CPU 逐像素路径。

### 4.1 力配置

| 参数                 | 类型             | 默认值           | 说明                                                                                                             |
| ------------------ | -------------- | ------------- | -------------------------------------------------------------------------------------------------------------- |
| `ForcePatternType` | `ForcePattern` | `Directional` | 力模式枚举。详见 [5.4 ForcePattern](#54-forcepattern)。                                                                 |
| `Force`            | `Vector2`      | `(0, -1)`     | 力的方向和基础大小。• `Directional`：所有位置受此固定方向力• `Point`/`Attractor`/`Repulsor`：使用长度作为力大小，方向由位置决定• `Vortex`：使用长度作为切向力大小  |
| `ForceRadius`      | `float`        | `100`         | 力的作用半径（**世界单位**）。值越大影响区域越广。内部会转换为像素半径：`pixelRadius = ForceRadius / FluidWorldSize.X × SimulationResolution.X`。 |
| `SwirlStrength`    | `float`        | `1.0`         | 旋涡力的旋转强度。仅 `Vortex` 模式生效。产生切向力的倍率，`0` = 无旋转效果。                                                                 |
| `FalloffExponent`  | `float`        | `2.0`         | 力随距离衰减的指数。`0` = 均匀力场（无衰减）；值越大边缘力越弱。计算公式：`falloff = (1 - dist/radius) ^ FalloffExponent`。                       |

### 4.2 作用形状

| 参数                  | 类型              | 默认值      | 说明                                                                                                                                |
| ------------------- | --------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `EmissionShapeType` | `EmissionShape` | `Circle` | 力的作用形状枚举。同 [FluidEmitter.EmissionShapeType](#32-发射形状)。                                                                            |
| `ShapeSize`         | `Vector2`       | `(1, 1)` | 力形状尺寸（**比例值**，非世界单位）。• `Circle`：`X` 为半径比例（实际半径由 `ForceRadius` 决定）• `Rect`：`X/Y` 为半宽/半高比例• `Line`：`X` 为半宽比例• `TextureMask`：忽略，使用遮罩 |
| `MaskTexture`       | `Texture2D`     | `null`   | 纹理遮罩。仅 `TextureMask` 模式生效。**注意**：`TextureMask` 会强制走 CPU 逐像素路径，性能较低。                                                               |

### 4.3 生命周期

| 参数            | 类型      | 默认值     | 说明                                               |
| ------------- | ------- | ------- | ------------------------------------------------ |
| `Active`      | `bool`  | `true`  | 是否激活力发射器。`false` 时停止施加力。                         |
| `Lifetime`    | `float` | `0`     | 生命周期（秒）。`0` = 永不过期。到期后根据 `AutoDestroy` 决定行为。     |
| `AutoDestroy` | `bool`  | `false` | 生命周期到期后是否自动销毁节点。`false` 时仅将 `Active` 置为 `false`。 |

### 4.4 GPU vs CPU 路径

| 路径      | 触发条件                                                        | 性能 | 说明                                                                             |
| ------- | ----------------------------------------------------------- | -- | ------------------------------------------------------------------------------ |
| GPU 并行  | `EmissionShapeType ≠ TextureMask` 且无 `CollisionShape2D` 子节点 | 高  | 力参数注册到 `FluidSim.ForceEmitters` 列表，由 `apply_force_emitter.glsl` 在 GPU 端并行计算。   |
| CPU 逐像素 | `EmissionShapeType = TextureMask` 或有 `CollisionShape2D` 子节点 | 低  | `ApplyForceToImageCPU` 逐像素写入 `InputForcesImg`，需调用 `MarkInputForcesDirty()` 上传。 |

> **性能建议**：力发射器尽量使用 `Circle`/`Rect` 等 GPU 路径形状；`TextureMask` 仅用于需要复杂遮罩的场景。

## 五、枚举类型参考

### 5.1 EmissionShape

发射形状枚举，定义粒子/力在空间中的分布方式。

| 值             | 说明                                        |
| ------------- | ----------------------------------------- |
| `Point`       | 点状发射，所有粒子从发射器中心点发出。                       |
| `Circle`      | 圆形发射，粒子在圆形区域内均匀面积采样（`sqrt(rand)` 保证均匀分布）。 |
| `Rect`        | 矩形发射，粒子在矩形区域内均匀随机分布。                      |
| `Line`        | 线段发射，粒子沿水平线段采样，垂直方向有 ±0.1 的微小随机偏移。        |
| `TextureMask` | 纹理遮罩发射，根据遮罩纹理的 Alpha 通道决定粒子分布位置（拒绝采样法）。   |

### 5.2 EmissionMode

发射模式枚举，定义发射时机和频率。仅 `FluidEmitter` 使用。

| 值               | 说明                                   |
| --------------- | ------------------------------------ |
| `Continuous`    | 持续发射，按 `EmitInterval` 间隔每帧发射粒子。      |
| `SingleBurst`   | 单次爆发，仅发射一次（`BurstCount` 个粒子）后停止。     |
| `PeriodicBurst` | 周期性爆发，按 `BurstInterval` 间隔周期性发射一组粒子。 |

### 5.3 VelocityPattern

速度方向模式枚举，定义粒子发射时的速度方向计算方式。仅 `FluidEmitter` 使用。

| 值             | 说明                                                                          |
| ------------- | --------------------------------------------------------------------------- |
| `Directional` | 定向模式：所有粒子沿 `EmitVelocity` 方向发射，速度大小一致。                                      |
| `Radial`      | 径向模式：粒子从发射器中心向外径向发射，速度大小为 `EmitVelocity.Length()`，可叠加 `VelocityFalloff` 衰减。 |
| `Random`      | 随机模式：粒子在随机方向上发射，速度大小等于 `EmitVelocity.Length()`。                             |

### 5.4 ForcePattern

力模式枚举，定义力发射器施加力的方向计算方式。仅 `FluidForceEmitter` 使用。

| 值             | 说明                                             |
| ------------- | ---------------------------------------------- |
| `Directional` | 固定方向力，所有位置的力向量相同（如风力、水流）。                      |
| `Point`       | 从中心点辐射的力，力向量沿径向方向（正值为斥力，负值为引力）。                |
| `Vortex`      | 旋涡力，力向量沿切线方向，产生旋转效果。叠加 `SwirlStrength` 控制旋转强度。 |
| `Attractor`   | 向心力，力向量指向中心点（引力井效果）。                           |
| `Repulsor`    | 离心力，力向量背离中心点（斥力场效果）。                           |

### 5.5 RangeSampleMode

范围采样模式枚举，当使用 `CollisionShape2D` 定义发射范围时，控制粒子在范围形状内的分布方式。

| 值          | 说明                             |
| ---------- | ------------------------------ |
| `Interior` | 内部采样：粒子在形状内部区域均匀随机分布。          |
| `Edge`     | 边缘采样：粒子仅在形状边缘/边界上分布（如圆周、矩形周长）。 |

***

## 六、坐标系统说明

本插件涉及三套坐标系，理解它们的区别对正确使用发射器至关重要：

### 6.1 世界坐标（World Space）

Godot 节点的 `GlobalPosition` 所在坐标系，单位为像素。发射器位置、`FluidWorldSize`、`ForceRadius` 都使用世界坐标。

### 6.2 流体 UV 坐标（UV Space `[0,1]`）

以流体域中心为 `(0.5, 0.5)`，将世界坐标归一化到 `[0,1]` 范围。**WFS splat shader 期望此坐标**。

- 转换方法：`FluidSimulation2D.WorldToFluidUV(worldPos)`
- 使用场景：`FluidEmitter` 注入粒子位置、`QueueDraw` 的 `uvPosition` 参数。

### 6.3 流体像素坐标（Pixel Space）

以流体域左上角为 `(0, 0)`，右下角为 `SimulationResolution`。**力发射器 GPU shader 期望此坐标**。

- 转换方法：`FluidSimulation2D.WorldToFluidPos(worldPos)`
- 使用场景：`FluidForceEmitter` 的 `CenterX/Y` 参数、障碍物力计算。

> **关键注意**：混用两套坐标会导致发射器位置完全错误。`FluidEmitter.EmitInternal` 已正确处理：先用世界坐标生成速度（径向/旋涡需要），再将点位转换为 UV 坐标供 splat 使用。

### 6.4 跟随节点偏移

若设置了 `FollowNodePath`，流体域中心会跟随该节点。所有坐标转换方法（`WorldToFluidUV`/`WorldToFluidPos`/`WorldToDyePos`）都会自动减去跟随节点的 `GlobalPosition` 作为域中心，无需手动处理。

## 七、渲染管线流程

每帧在渲染线程执行的完整流程（WFS 架构）：

```
1. ProcessBatchQueue          处理批量绘制队列（Splat）
2. ProcessDomainShift         更新障碍物纹理 + 域偏移（Shift Texture）
3. ApplyForceEmitters         应用 GPU 力发射器
4. ApplyExternalInputs        应用外部输入力/颜色
5. ApplySplatRequests         应用 Splat 请求（鼠标/发射器）
6. ApplyObstacleForce         计算障碍物对流体的排斥力
7. ComputeCurl                计算涡度场（Curl）
8. ApplyVorticity             涡度增强（Vorticity Confinement）
9. ComputeDivergence          计算速度场散度
10. ClearPressure             压力衰减（Pressure × 0.8）
11. SolvePressure             Jacobi 迭代求解压力场（× PressureIterations）
12. SubtractPressureGradient  从速度场中减去压力梯度
13. ApplyBoundary             边界条件处理
14. AdvectVelocity            速度场平流
15. AdvectDye                 颜色/染料场平流
16. CopyObstacleTexture       复制当前障碍物纹理到上一帧缓冲
17. Display                   后处理着色（Shading）输出到显示纹理（EnableShading 时）
```

后处理输出纹理选择：仅染料（`TexIdColor`）→ 启用 Shading（`TexIdDisplayOutput`）。

参数与管线的对应关系：

| 参数                                | 影响的管线阶段                              |
| --------------------------------- | ------------------------------------ |
| `SplatRadius` / `SplatForce`      | 5. ApplySplatRequests                |
| `Curl` / `EnableVorticity`        | 7-8. ComputeCurl + ApplyVorticity    |
| `PressureIterations` / `Pressure` | 10-11. ClearPressure + SolvePressure |
| `VelocityDissipation`             | 14. AdvectVelocity（衰减乘法）             |
| `DensityDissipation`              | 15. AdvectDye（衰减乘法）                  |
| `ObstacleForceStrength`           | 6. ApplyObstacleForce                |
| `EnableShading`                   | 17. Display                          |

## 八、常见用法示例

### 8.1 鼠标绘制流体

参考 `Scenes/WorldFluidTest.cs`：

```csharp
// 将鼠标世界坐标转换为 UV
var uv = fluidSim.WorldToFluidUV(mouseWorldPos);
// 计算鼠标移动速度作为注入速度
var velocity = deltaUV * fluidSim.SplatForce;
// 注入颜色和速度
fluidSim.QueueDraw(uv, color * 0.15f, velocity, colorRadius: 0.5f, velocityRadius: 0.8f);
```

### 8.2 烟雾发射器

配置 `FluidEmitter` 模拟烟雾上升：

```
EmissionModeType = Continuous
EmitInterval = 0.02
EmissionShapeType = Circle
ShapeSize = (30, 30)          # 30px 半径
EmitColor = (0.3, 0.3, 0.3, 0.6)  # 灰色烟雾
EmitVelocity = (0, -80)       # 向上飘
VelocityPatternType = Directional
ColorRadius = 0.6
VelocityRadius = 0.8
SwirlStrength = 5             # 轻微旋转
```

对应 `FluidSimulation2D` 参数：

```
DensityDissipation = 0.8      # 缓慢消散
VelocityDissipation = 0.1     # 速度保持
Curl = 35                     # 涡度增强
```

### 8.3 爆炸效果

配置 `FluidEmitter` 单次爆发：

```
EmissionModeType = SingleBurst
BurstCount = 200
EmissionShapeType = Circle
ShapeSize = (5, 5)
EmitColor = (1.0, 0.4, 0.1, 1.0)  # 橙红色
VelocityPatternType = Radial
EmitVelocity = (0, 200)       # 仅用长度
VelocityFalloff = 1.5         # 边缘稍慢
ColorRadius = 0.4
VelocityRadius = 0.6
```

### 8.4 风力发射器

配置 `FluidForceEmitter` 持续向右吹风：

```
ForcePatternType = Directional
Force = (150, 0)              # 向右
ForceRadius = 200             # 200px 影响范围
EmissionShapeType = Rect
ShapeSize = (1, 2)            # 宽矩形
FalloffExponent = 1.5
```

### 8.5 旋涡力发射器

配置 `FluidForceEmitter` 产生旋涡：

```
ForcePatternType = Vortex
Force = (0, 200)              # 切向力大小
ForceRadius = 150
SwirlStrength = 2.0           # 旋转强度
EmissionShapeType = Circle
FalloffExponent = 2.0
```

### 8.6 引力井（吸引流体）

配置 `FluidForceEmitter` 吸引周围流体：

```
ForcePatternType = Attractor
Force = (0, -100)             # 向心力大小（负号无关，仅用长度）
ForceRadius = 300
EmissionShapeType = Circle
FalloffExponent = 1.0         # 缓慢衰减
```

### 8.7 跟随摄像机的无限流体

在 `FluidSimulation2D` 上：

```
FluidWorldSize = (1920, 1080)
FollowNodePath = ^Camera2D    # 指向摄像机节点
SimulationResolution = (228, 128)
```

摄像机会通过 `FluidDomainOffset` 自动触发 Shift Texture，实现流体域跟随摄像机移动的"无限流体"效果。
